## 🧠 Overview

Retouch4me is a bundle of separate AI retouching plug-ins: each module performs one specific job on a portrait or product shot, such as healing skin, dodging and burning, evening out skin tone, adding volume to a face or cleaning a backdrop.

Published by Retouch4me. Category: AI retouching plug-ins.

The archive in this repository contains the plug-in suite itself plus the integration files for Adobe Photoshop 2020 or newer, Adobe Lightroom Classic, Capture One.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🩹 Heal | Removes pimples, scars and small blemishes on a separate layer and keeps skin texture. |
| 🌘 Dodge and Burn | Adds volume by lightening and darkening planes of the face as a frequency-separated layer. |
| 🎨 Skin Tone | Evens local colour patches and redness while leaving highlights and shadow colour intact. |
| 📐 Portrait Volumes | Shapes light on the face without repainting masks by hand. |
| 🧵 Fabric | Removes creases and lint from clothing in product and fashion shots. |
| 🧹 Clean Backdrop | Removes dust, stains and scuffs from studio backgrounds. |
| 👁️ Eye Vessels | Clears red vessels in the sclera without desaturating the iris. |
| 🗂️ Layer Output | Each module writes to its own layer, so results can be blended or masked afterwards. |

## Additional Information for Windows Users

Settings created in Retouch4me are stored in the plug-in's own preset folder, so a reinstall keeps user presets and replaces only program files.

Removing the plug-in goes through the host application's plug-in manager or the Windows uninstall entry, depending on how it was registered.
